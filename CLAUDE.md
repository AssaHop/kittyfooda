# KittyFooda — правила и контекст для Claude

## Проект
- Ханафуда (кои-кои) с кошками, **Telegram Mini App** бота `@KittyFooda_bot`.
- Вся игра в одном файле `index.html` (canvas, vanilla JS). Бэкенд — serverless-функции в `api/` на Vercel + Supabase.
- Общение с пользователем — на русском.
- Полное состояние проекта: `GAME-STATE.md`. **Начинать с §0** — там текущий статус и следующие шаги.

## Структура
- `index.html` — игра целиком: колода, яку, ИИ, отрисовка, журнал событий, покупки и прогресс.
- `api/` — `save-progress.js`, `create-invoice.js`, `telegram-webhook.js`, `_verify.js` (проверка initData);
  `TODO-security.md` — открытые вопросы безопасности.
- `cards/` — внешний арт карт. Файл `cards/<имя>.png|jpg|svg` перекрывает встроенный `CARD_SVG`.
- `tools/ai-sim/` — headless-харнесс прогонов ИИ (`sim.js`, `pimc.js`, `yakucheck.js`, `logcheck.js`, `README.md`).
  На Vercel не деплоится (`.vercelignore`).
- `docs/archive/` — история калибровки портфельного ИИ и рекап первой сессии.

## ИИ
- Normal/Hard — портфельный ИИ (`progressiveValue` с точным DP). Мастер (`DIFF===4`) — **PIMC** (функции `pimc*`):
  модель подставляет скрытые карты и доигрывает партию до конца, лимит `PIMC_BUDGET_MS`.
  Полезность ограничена тем, сколько каждому не хватает до цели партии (`pimcUtil`). Подробно — `GAME-STATE.md` §3, §5.10, §5.11.
- **Не подкручивать веса вручную** («искусственно»). Любое изменение ИИ проверять прогоном:
  `node tools/ai-sim/sim.js <a.html|pimc:N> <b.html> diffA diffB pairs seed label`.
  Раздачи парные. Контроль «версия против самой себя» ≈ 50%. Выводы делать только при N ≥ 150–200 и смотреть на 95%-й интервал.
- Отложенные слабости PIMC (§5.11) не трогать, пока пользователь не попросит.
- Журнал партий пользователь присылает сам. Партии нового Мастера отмечены `engine:"pimc"` в событиях.

## Правила
- **UI не трогать без описания и референсов от пользователя.**
- Vercel деплоит `main` автоматически. Пушить в `main`, только если прогон прошёл успешно; разрешение на пуш и мердж пользователь дал.
  Рабочая ветка — `ai/exact-progressive-value`, в `main` вливать fast-forward.
- Клон неглубокий: если git не видит удалённую ветку, добавить refspec через `git config --add remote.origin.fetch ...`.
- Сайт `*.vercel.app` из контейнера недоступен. Проверку в живой игре делает пользователь.
