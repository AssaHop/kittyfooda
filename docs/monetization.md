## Часть 1. Что делают другие

### 1.1 Особенности Telegram

| Факт | Что значит для нас |
|---|---|
| Цифровые товары в ботах и Mini Apps продаются **только за Telegram Stars**; Telegram отключал ботов, принимавших оплату за цифровое мимо Stars | рыбки, подсказки, косметику продаём только за ⭐ (у нас уже так) |
| Пользователь покупает звезду примерно за $0.02, разработчик выводит примерно по $0.013, вывод через Fragment после ~21 дня, минимум 1000 ⭐ | 100 ⭐ ≈ $2 для игрока, ≈ $1.3 нам |
| Mini Apps поддерживают **подписки за Stars** (несколько уровней) | можно сделать VIP-подписку без своей платёжки |
| Mini App может **дарить подарки за Stars** пользователям | призы турниров, награды за рефералов |
| Реклама в Mini Apps — сторонние сети: **AdsGram** (видео за награду), Monetag, RichAds и др. | AdsGram — самый частый выбор для игр |
| Главный двигатель роста в Telegram-играх — **рефералы с наградой обоим** | приглашение друга = рыбки обоим |
| Ретеншн держат **ежедневные задания и стрики**, плюс лидерборды | дейлики и стрик — в первую очередь |

| 15 | **Сезонный пропуск** | месяц, бесплатная и платная дорожка наград | 🟡 (v3) когда будет много косметики/арта |

| 22 | **Плата за силу (pay-to-win)** | ИИ слабее за деньги и т. п. | ❌ ломает смысл игры |

### 1.3 Принципы (из источников и здравого смысла)

- **Гибрид**: покупки за ⭐ + видео за награду дают больше, чем что-то одно.
- **Вся платность — по желанию**: играть можно бесплатно и без рекламы.
- **Реклама только по кнопке игрока**, без принудительных вставок.
- **Первая покупка — самое важное событие**: дешёвый стартовый набор.
- **Награда считается на сервере**, клиент её не задаёт.

## Часть 2. Задание «Рыбки v1»

### Цель
Ввести валюту 🐟: игрок получает её за партии и регулярность, тратит на
подсказки. Это фундамент для магазина, заданий и рекламы следующих версий.

### Входит в v1
1. **Баланс рыбок** у игрока, хранится в базе, сервер — единственный источник правды.
2. **Награда за партию** — считает сервер по результату и сложности
   (`progression.md` §2): победа 10 / поражение 2, бонусы за очки и яку,
   множитель Easy ×1 · Normal ×3 · Hard ×8 · Мастер ×20. Ответ сервера — новый
   баланс и разбивка «за что».
3. **Стрик входа** (`progression.md` §3): награда за 1–7 день подряд, засчитывается
   по первой сыгранной партии дня; день — по серверному времени UTC+3 **[решить]**.
4. **Первые 3 партии дня ×2**, первая победа дня +20.
5. **Подсказки за рыбки**: «лучший ход» за 50 🐟 (оставляем покупку за ⭐ как есть).
6. **Потолок**: не больше 2000 🐟 в сутки за партии (защита от накрутки).
7. **Интерфейс-минимум** (по описанию пользователя):
   - счётчик 🐟 в шапке игры и на стартовом экране;
   - в итоге партии строка «+N 🐟 (победа 10, яку +4, ×8 Hard, ×2 первые игры)»;
   - уведомление о стрике «День 3 подряд: +20 🐟».

### Не входит в v1 (следующие версии)
- v2: магазин косметики (сукно/рубашки кодом), пакеты 🐟 за ⭐, стартовый набор,
  видео за награду AdsGram, ежедневные и недельные задания, рефералы.
- v3: достижения, сезонный пропуск, VIP-подписка, копилка, лидерборды, наборы карт (арт).

### База (миграция, выполняет пользователь в Supabase)
`users`: `coins int default 0`, `coins_total int default 0`,
`streak_days int default 0`, `last_play_day date`, `games_today int default 0`,
`wins_today int default 0`, `coins_today int default 0`.
Плюс таблица журнала начислений `coin_log (telegram_id, delta, reason, created_at)`
— чтобы разбирать споры и накрутки.

### Сервер
- `/api/save-progress` с `result` дополнительно принимает `diff`, `points`,
  `yaku` (список названий), считает награду, обновляет стрик и счётчики дня,
  пишет `coin_log`, возвращает `{coins, gained, breakdown, streak}`.
- `action: 'spend_coins'` с `item: 'hint'` — списывает 🐟 атомарно, отказ при нехватке.
- Цены и награды — в одном файле констант (как `_catalog.js`).

### Проверка (критерии приёмки)
- Победа на Hard дома → в базе `coins` выросли на расчётную сумму, в `coin_log` строка.
- Второй день подряд → стрик 2 и бонус; пропуск дня → стрик 1.
- Подсказка за 🐟 при нехватке — отказ без списания; при достатке — списание ровно 50.
- Потолок 2000/сутки срабатывает.
- Харнесс без телефона: прогон партий против сервера-заглушки, проверка сумм.

### Решить до начала
1. Название валюты (рыбки 🐟?) и уровня.
2. Множители ×1/×3/×8/×20 — ок?
3. Часовой пояс для «дня».
4. Цена подсказки в 🐟 (50?).
5. Как должен выглядеть итог партии и где счётчик — набросок или описание.
