# Раскладка игрового экрана (UI v3, 2026-10-10)

Ветка `ui/screen-layout`. **В `main` пока не влита** — ждёт решения пользователя
после просмотра на телефоне. Скриншоты: `docs/ui/iphone15-turn.png`,
`docs/ui/iphone15-choose.png`.

## Шаблон v2 (первое ТЗ, 2026-10-09; заменён макетом v3)

Экран-образец — iPhone 15, **1179×2556** физических px. Пиксельные значения
относительные (масштабируются), проценты — от высоты экрана.

- Всё игровое поле в безопасной зоне: отступ сверху **8%**, снизу **7%**,
  ширина зоны **1100**.
- Середина экрана, **40%** высоты — стол; фон стола **95%** ширины экрана.
- Карты **190×310**.
- От левого края зоны **10 px** — колода (1 карта), по вертикали по центру;
  дальше **40 px**, дальше стол — 4 карты через **20 px**.
- Внизу **100 px** от края зоны — полоса, в ней кнопка «Мяу-Мяу».
- Карты игрока — 2 ряда по 4, по вертикали тоже **20 px**.
- Карты противника — одна карта, слева выровнена по левой карте игрока,
  **80 px** от верха зоны.
- В промежутках между столом и картами игрока / ИИ — ячейки для показа яку.
- Сложность — на другом экране; подсказки — над картой ## Макет v3 (текущий, 2026-10-10)

Макет: `docs/ui/layout-v3.png` (исходник `layout-v3.svg`). Основа — схема
пользователя 1179×2556; размеры в ней считаются долями экрана. Что в схеме
не сходилось и как решено:

- Подписи «поля 8%» противоречили «зона 92%, 1084×2351». **Решение
  пользователя: поля 4%** с каждой стороны → зона 92% × 92%.
- Ряд стола со схемы (колода + 4 карты 180 px, промежутки 112 + 3×56)
  занимал 1180 px, то есть шире зоны. **По слову пользователя промежуток x = 30**,
  у колоды — 2x. Ширина карты берётся из условия «ряд = ширина зоны»:
  5w + 5x = 1084,7 → **w = 186,9, h = 1,5w = 280,4** (пропорция 2:3).
- Стол — **место на 3 ряда по 4** (3h + 2x = 901), колода по центру этого места.
- Полоса «Мяу-Мяу»/сообщений (100) — под рукой через x, под полосой 50 до края
  зоны. Нижний отступ 5% из схемы заменён этим, рука поднята на 62 px.

Счёт по высоте (iPhone 15, реф. px): поле 102 · отступ 5% зоны 118 (в нём шапка:
счёт, раунд, 💡) · карта ИИ 280 · ячейки яку ИИ **141** · стол 901 · ячейки яку
игрока **141** · рука 280 + 30 + 280 · 30 · полоса 100 · 50 · поле 102 = 2556.
Ячейкам яку остаётся немного — это цена места под 3 ряда стола.

## Как реализовано

Модуль «Игровой стол: раскладка под экран (макет v3)» в `index.html`.
Константы: `REF_W=1179`, `SAFE_M=0.04`, `SAFE_W=REF_W·0.92`, `ZONE_PAD=0.05`,
`B_GAP=30`, `BCW=(SAFE_W−5·B_GAP)/5`, `BCH=1.5·BCW`, `TABLE_ROWS=3`,
`BAND_H=100`, `BAND_BOTTOM=50`, `HEADER_H=80`, `MIN_CELLS=120`.

**Масштаб.** `resizeCanvas()`: холст на весь экран, внутреннее разрешение ×
devicePixelRatio. `k = ширина/1179`; если по высоте не помещается (промежуток
под ячейки яку < `MIN_CELLS`), `k` уменьшается, поле центрируется по ширине
(поля по бокам становятся больше 4%). Отступ сверху/снизу = max(4%, safe area
Telegram). Пересчёт на `resize` и событиях Telegram
`viewportChanged/safeAreaChanged/contentSafeAreaChanged/fullscreenChanged`.

**Одна функция `boardLayout()`** — и для отрисовки, и для хит-теста
(`boardClick`), плюс `tableLayout(L)`, `playerHandLayout(L)`, `choiceButtons(L)`.

Сверху вниз:
1. Шапка в верхнем отступе зоны: «ВЫ n : m ИИ», «Раунд N · до 30 (★ Мяу-Мяу)»,
   справа 💡 (подсказка, с числом купленных).
2. Карта ИИ рубашкой с числом карт — у левого края зоны, над колодой. Справа
   (на первой колонке стола) — карта, которую ИИ сейчас играет; «ИИ ходит…».
3. Ячейки ИИ: 👑 яркие, 🧸 животные, 🎀 ленты, 🐾 простые + очки раунда.
4. Стол на сукне (95% ширины экрана, высота — место на 3 ряда): колода слева
   по центру, число карт под ней; взятая из колоды карта — поверх колоды.
   Карты стола по месяцу, 4 колонки; 2–3 ряда полного размера, по центру места;
   больше 12 — ряды ужимаются. Подсветка целей захвата; в `captureSelect` — клик.
5. Ячейки игрока — как у ИИ.
6. Рука 2×4 по центру экрана, по месяцу (`G.pHand` не переупорядочивается).
   Выбранная карта поднята на 30 и светится жёлтым, подсказка — голубая рамка.
7. Полоса 100: `G.msg` или, в фазе `choose`, кнопки «✋ СТОП» / «🐱 МЯУ-МЯУ».

Замер (`measure.js`): iPhone 15 — карта 186,9×280,4, поля 4/4/4%, отступ 5%,
2x = 60, x = 30, ряд = 1084,7, ячейки 141; Android 412×915 — ячейки 176;
16:9 375×667 — не помещается по высоте, k уменьшен, карта 149×223, ячейки 98,5
(по бокам поля 11,7%).

## Решения, принятые сверх ТЗ (подтвердить у пользователя)

1. Стол — по середине между картой ИИ и рукой; 2 ряда центрируются в месте на 3.
2. Карта хода ИИ — справа от его карты; карта из колоды — поверх колоды.
3. Шапка (счёт, раунд, 💡) — в верхнем отступе зоны 5%.
4. Полоса «Мяу-Мяу»: 100 высотой, 30 под рукой, 50 до края зоны.
5. Сложность — ряд кнопок Easy/Normal/Hard/Мастер на стартовом экране.

## Арт

- Карта в слот 187×280 (на iPhone 15 — 1:1). Рекомендуемый размер файла
  **400×600** (запас для планшетов), пропорция **2:3**.
- `cards/<имя>.png|jpg|svg` перекрывает встроенный SVG (как раньше).
  `drawFitted()`: если пропорции совпадают с слотом (±6%) — на весь слот,
  иначе вписывается по центру на фоне цвета месяца (встроенные SVG 120×160
  поэтому с цветными полосами по бокам — это ожидаемо до нового арта).
- Рубашка: `cards/back.png|jpg|svg`, если файла нет — рисуется кодом.

## Не сделано / открыто

- Стартовый экран, журнал, итог раунда, попап «Мяу-Мяу» — старые
  (450×800, просто масштабируются по центру, `setLegacyTransform`).
  Ждут описания от пользователя.
- Убрана старая панель «прогресс к яку» (чек-лист карт) — места нет;
  вернуть, если пользователь попросит.
- Фон стола/экрана картинкой — пока не поддержан.
- Проверено только в headless Chromium (393×852, 412×915, 375×667),
  на живом телефоне в Telegram — нет. В fullscreen Telegram верхний inset
  может быть больше 4% — тогда отступ берётся из inset, а k при нехватке высоты уменьшается.

## Проверка без телефона

`tools/ui-shots/` (Playwright из `/opt/node-tools`, не деплоится):
- `node tools/ui-shots/shot.js file://$PWD/index.html out.png 393 852 mid|choose|deal|start`
- `node tools/ui-shots/measure.js` — замер размеров на 3 экранах (поля, карта, x, ряд, ячейки);
- `node tools/ui-shots/click.js` — выбор сложности + 6 ходов кликами против Мастера.
