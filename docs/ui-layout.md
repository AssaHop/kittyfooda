- **Шапка:** счёт матча «ВЫ n : m ИИ» по центру, 💡 справа; «Раунд N · до 30» убран
  по слову пользователя, слева только «★ Мяу-Мяу», когда объявлено.
  Отдельные счётчики очков раунда в ячейках убраны.
- **Яку — пока просто место:** пунктирные рамки над и под столом, внутри строка

- Стол — **2 ряда по 4** (2h + x = 591); больше 8 карт — ряды ужимаются.
  **Колода меньше карт стола** (0,75 → 140×210), по центру своей колонки.

## Как реализовано

Модуль «Игровой стол: раскладка под экран (макет v3)» в `index.html`.
Константы: `REF_W=1179`, `SAFE_M=0.04`, `SAFE_W=REF_W·0.92`, `ZONE_PAD=0.05`,
`B_GAP=30`, `BCW=(SAFE_W−5·B_GAP)/5`, `BCH=1.5·BCW`, `TABLE_ROWS=2`, `DECK_K=0.75`,
`BAND_H=100`, `BAND_BOTTOM=50`, `HEADER_H=80`, `MIN_CELLS=200`.

**Масштаб.** `resizeCanvas()`: холст на весь экран, внутреннее разрешение ×
devicePixelRatio. `k = ширина/1179`; если по высоте не помещается (промежуток
под ячейки яку < `MIN_CELLS`), `k` уменьшается, поле центрируется по ширине
(поля по бокам становятся больше 4%). Отступ сверху/снизу = max(4%, safe area
Telegram). Пересчёт на `resize` и событиях Telegram
`viewportChanged/safeAreaChanged/contentSafeAreaChanged/fullscreenChanged`.

**Одна функция `boardLayout()`** — и для отрисовки, и для хит-теста
(`boardClick`), плюс `tableLayout(L)`, `playerHandLayout(L)`, `choiceButtons(L)`.

Сверху вниз:
1. Шапка в верхнем отступе зоны: «ВЫ n : m ИИ», «Раунд N · до 30 (★ Мяу-Мяу)»,
   справа 💡 (подсказка, с числом купленных).
2. Карта ИИ рубашкой с числом карт — у левого края зоны, над колодой. Справа
   (на первой колонке стола) — карта, которую ИИ сейчас играет; «ИИ ходит…».
3. Ячейки ИИ: 👑 яркие, 🧸 животные, 🎀 ленты, 🐾 простые + очки раунда.
   Ширина ячейки — по числу карт в ней, чтобы мини-карты везде были одного
   размера; карты внахлёст, у каждой виден левый край с месяцем (≥ 32%);
   при многих картах — 2–3 ряда (`miniCardsLayout`). На iPhone 15 мини-карта
   ~90×134 при ~23 взятых картах, крупнее, когда карт меньше.
4. Стол на сукне (95% ширины экрана, высота — 2 ряда): колода 0,75 слева
   по центру, число карт под ней; взятая из колоды карта — полного размера
   поверх колоды. Карты стола по месяцу, 4 колонки, 2 ряда; больше 8 — ряды
   ужимаются в ту же высоту. Подсветка целей захвата; в `captureSelect` — клик.
5. Ячейки игрока — как у ИИ.
6. Рука 2×4 по центру экрана, по месяцу (`G.pHand` не переупорядочивается).
   Выбранная карта поднята на 30 и светится жёлтым, подсказка — голубая рамка.
7. Полоса 100: `G.msg` или, в фазе `choose`, кнопки «✋ СТОП» / «🐱 МЯУ-МЯУ».

Замер (`measure.js`, физ. px): iPhone 15 — карта 186,9×280,4, колода 140×210,
поля 4/4/4%, отступ 5%, x = 30, ряд = 1084,7, ячейки 296; Android 412×915 —
ячейки 339; 16:9 375×667 — k уменьшен по высоте, карта 158×237, по бокам 9,3%.

## Решения, принятые сверх ТЗ (подтвердить у пользователя)

1. Стол — по середине между картой ИИ и рукой.
2. Карта хода ИИ — справа от его карты; карта из колоды — поверх колоды.
3. Шапка (счёт, раунд, 💡) — в верхнем отступе зоны 5%.
4. Полоса «Мяу-Мяу»: 100 высотой, 30 под рукой, 50 до края зоны.
5. Сложность — ряд кнопок Easy/Normal/Hard/Мастер на стартовом экране.

## Арт

- Карта в слот 187×280 (на iPhone 15 — 1:1). Рекомендуемый размер файла
  **400×600** (запас для планшетов), пропорция **2:3**.
- `cards/<имя>.png|jpg|svg` перекрывает встроенный SVG (как раньше).
  `drawFitted()`: если пропорции совпадают с слотом (±6%) — на весь слот,
  иначе вписывается по центру на фоне цвета месяца (встроенные SVG 120×160
  поэтому с цветными полосами по бокам — это ожидаемо до нового арта).
- Рубашка: `cards/back.png|jpg|svg`, если файла нет — рисуется кодом.
