# ai-sim — headless-прогоны ИИ (Node, без зависимостей)

- `sim.js` — матч версия A против версии B. Каждая версия в своём `vm`-контексте,
  решающей стороне отдаётся `G` с её точки зрения (`G.turn='ai'`). Парные раздачи:
  каждая колода играется дважды со сменой мест. Печатает win-rate, 95% CI, время PIMC.
- `pimc.js` — прототип PIMC (то же, что в `index.html`, без лимита времени).
- `yakucheck.js` — сверка `pimcYakuPts` с `getYaku` на случайных наборах.
- `logcheck.js [html]` — прогон настоящего игрового цикла (таймеры, клики игрока),
  печатает, что попало в журнал событий.

Перед выводами: sanity «версия против самой себя» ≈ 50%, N ≥ 150–200
(на N=50 разброс ±14 п.п. — см. GAME-STATE.md §5.10).
